# 🌕 วันลอยกระทง 3D (Loy Krathong Festival 3D Experience)

เกมและโลกจำลอง 3D เสมือนจริงในค่ำคืนเทศกาล **"วันเพ็ญเดือน ๑๒"** (วันลอยกระทง) พัฒนาด้วยเทคโนโลยี **Three.js** และหลักการออกแบบ 3D WebGL (พร้อมแนวทางเทียบเคียง **Babylon.js**) ให้บรรยากาศงานวัดไทยยามค่ำคืนอันตระการตา มีพระจันทร์เต็มดวงส่องแสงนวล สายน้ำระยิบระยับเต็มไปด้วยกระทงลอยประทีป และตัวละคร 3D ในชุดไทยดั้งเดิมที่สามารถเดินเที่ยวงานได้อย่างอิสระ

---

## 🌟 ฟีเจอร์เด่นภายในเกม (Key Features)

### 1. 🌌 บรรยากาศค่ำคืนวันเพ็ญและสายน้ำ (Night Atmosphere & Water)
- **พระจันทร์เต็มดวง (Full Moon):** ดวงจันทร์ทรงกลม 3D พร้อมพื้นผิวหลุมอุกกาบาต (Craters) เปล่งแสงรัศมีนวล (Lunar Halo) และสะท้อนแสงเงาประกายสีทอง/เงินลงบนผิวน้ำอย่างสมจริง
- **สายน้ำระยิบระยับ (Animated Rippling River):** สายน้ำที่มีคลื่นน้ำเคลื่อนไหวแบบ Real-time ด้วย Vertex Displacement และ Normal Maps สะท้อนแสงเทียนและโคมไฟ
- **โคมลอยยี่เป็ง (Sky Lanterns):** โคมลอยสีส้มอบอุ่นลอยขึ้นสู่ฟากฟ้าเคียงคู่หมู่ดาวนับพัน
- **พลุดอกไม้เพลิง (Particle Fireworks):** ระบบพลุไฟอนุภาคระเบิดสว่างไสวบนท้องฟ้า พร้อมแสงวาบตกกระทบหลังคาวัดและผิวน้ำ

### 2. 🛕 สถาปัตยกรรมงานวัดไทย (Thai Temple Fairgrounds)
- **พระบรมธาตุเจดีย์สีทอง (Golden Chedi):** องค์เจดีย์ทรงระฆังคว่ำสีทองอร่าม ส่องไฟ Spotlight ตระการตา
- **พระอุโบสถทรงไทย (Ubosot):** หลังคาซ้อน ๓ ชั้น ประดับช่อฟ้า ใบระกา และเสาสีแดงขาว
- **ชิงช้าสวรรค์ยักษ์ (Giant Ferris Wheel):** หมุนรอบอย่างสมจริงพร้อมไฟนีออน LED หลากสีสันที่กระเช้าและก้านหมุน
- **ธงราวและโคมประดับ (Bunting & Lanterns):** ธงสามเหลี่ยมหลากสีและโคมแขวนส่องสว่างทั่วบริเวณงานวัด

### 3. 🪷 ร้านค้าและกระทง 4 รูปแบบ (Krathong Shop & Floating)
- **ร้านกระทงลุงสมคิด:** ซุ้มไม้ไผ่ริมน้ำที่มีคุณลุงสมคิดคอยต้อนรับ
- **รูปแบบกระทง 4 ชนิด:**
  1. 🍃 **กระทงใบตองวิจิตร:** เย็บกลีบผกา กล้วยไม้ ดอกดาวเรือง สวยงามตามขนบไทยแท้ (ย่อยสลายได้ 100%)
  2. 🪷 **กระทงดอกบัวสวรรค์:** กลีบบัวสีชมพูขาวซ้อนชั้น เกสรทองคำ เสริมสิริมงคล
  3. 🐢 **กระทงขนมปังเต่าน้อย:** อบจากแป้งสาลีธรรมชาติ เป็นอาหารให้ปลาในคลอง
  4. ✨ **กระทงแก้วเรืองแสง:** กระทงนีออนแฟนซีเปล่งแสงออโรร่ากลางสายน้ำ
- **ปรับแต่งกระทง:**
  - เลือกสีเปลวเทียนมงคล (ทอง, ชมพู, ฟ้า, ขาว, ม่วง)
  - ใส่เหรียญนำโชคตามประเพณี (๑ บาท, ๕ บาท, ๑๐ บาท)
  - เขียนคำอธิษฐานจิต หรือเลือกคำอวยพรขอขมาพระแม่คงคา
- **พิธีลอยกระทง (Floating Ceremony):** เดินไปที่ท่าน้ำวัด ตัวละครคุกเข่าพนมมืออธิษฐานจิต นำกระทงจรดหน้าผาก และปล่อยลงสู่สายน้ำอย่างอ่อนช้อย พร้อมป้ายคำอธิษฐานเรืองแสงลอยเหนือกระทง และการจุดพลุเฉลิมฉลอง

### 4. 🚶 ตัวละคร 3D และ NPC (3D Character & Village Life)
- **ตัวละครผู้เล่น (Playable 3D Character):** สวมชุดไทยโบราณ (สไบเฉียงพาดบ่า โจงกระเบนสีม่วง พร้อมเข็มขัดทองและปิ่นปักผมดอกไม้)
- **ระบบแอนิเมชัน:**
  - ยืนสงบนิ่ง (Idle Breathing)
  - เดิน / วิ่ง (Walk & Sprint Animation ขาและแขนแกว่งอย่างเป็นธรรมชาติ)
  - กระโดด (Jump Physics)
  - ถือกะทงด้วยสองมือ และท่าคุกเข่าพนมมือลอยกระทง (Kneeling Prayer Ritual)
- **ผู้คนในงานวัด (NPCs):** ชาวบ้านในชุดไทยสีสันสดใสเดินเที่ยวงานวัด

### 5. 🎯 ซุ้มกิจกรรมและมินิเกมงานวัด (Mini-Games)
- **ร้านปาลูกโป่งงานวัด (Balloon Darts):** เล็งและปาลูกดอกแตกสะใจ 5 ดอก สะสมแต้มลุ้นรับรางวัลตุ๊กตาหมี
- **ซุ้มเซียมซีมงคลเจ้าแม่คงคา (Esiimsi):** เขย่ากระบอกเซียมซีไม้ไผ่ พร้อมบทกวีคำทำนายดวงชะตาภาษาไทยดั้งเดิม

### 6. 🎶 ดนตรีไทยและเสียงประกอบสังเคราะห์ (Web Audio API)
- บรรเลงเพลง **"วันเพ็ญเดือนสิบสอง (เพลงวันลอยกระทง)"** ด้วยเสียงสังเคราะห์ระนาดเอก, ฆ้องวง, ฉิ่ง, กลองไทย
- เสียงบรรยากาศริมน้ำ เสียงจิ้งหรีดเรไรยามค่ำคืน เสียงน้ำกระเพื่อม เสียงจุดพลุ และเสียงระฆังวัด
- **ไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก** (หมดปัญหาไฟล์เสียงโหลดไม่ติดหรือ 404)

## 🚀 วิธีเปิดใช้งานเกม (How to Run)

### วิธีที่ 1: รันด้วย Node.js
```bash
node server.js
```
เปิดบราวเซอร์ไปที่: `http://localhost:8080`

### วิธีที่ 2: รันด้วย Python
```bash
python server.py
```
เปิดบราวเซอร์ไปที่: `http://localhost:8080`

### วิธีที่ 3: ดับเบิ้ลคลิกเปิดไฟล์ `index.html` โดยตรง
สามารถดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดผ่านบราวเซอร์ที่รองรับ ES Modules ได้ทันที

## 💡 โครงสร้างสถาปัตยกรรม 3D (Three.js & Babylon.js Architecture)

โปรเจกต์นี้ถูกออกแบบเชิงโมดูลาร์ (Modular WebGL Architecture):

- `index.html`: โครงสร้างหน้าเว็บ, HUD, Glassmorphism UI, หน้าต่างมินิเกม
- `css/style.css`: ธีมงานวัดยามราตรี, แสงเรืองรองสีทอง/บัวชมพู, Responsive Mobile Support
- `js/main.js`: ควบคุม WebGL Rendering Loop, Camera Modes, Input Management
- `js/world.js`: สร้างฉากงานวัด, พระจันทร์, ดวงดาว, วัดไทย, ชิงช้าสวรรค์, ร้านค้า
- `js/water.js`: คำนวณคลื่นน้ำ ฟิสิกส์การลอย และการสะท้อนเงาของผิวน้ำ
- `js/character.js`: โครงสร้างโมเดลตัวละคร 3D ชุดไทย, การผูกข้อต่อ (Hierarchy Rigging) และแอนิเมชัน
- `js/krathong.js`: การขึ้นรูป 3D กระทง 4 ชนิด, เปลวเทียนพริ้วไหว, และระบบขบวนกระทงลอยน้ำ
- `js/fireworks.js`: ระบบ Particle Physics พลุไฟระเบิดแตกกระจาย
- `js/audio.js`: เอนจินสังเคราะห์เสียงดนตรีไทยและ SFX ผ่าน Web Audio API
- `js/minigames.js`: จัดการมินิเกมปาลูกโป่ง และระบบเซียมซีเสี่ยงทาย

### 📐 หมายเหตุการแปลงเทียบเป็น Babylon.js (Babylon.js Mapping):
หากต้องการต่อยอดหรือแปลงเป็น Babylon.js:
1. `THREE.PerspectiveCamera` ➡️ `BABYLON.ArcRotateCamera` หรือ `UniversalCamera`
2. `RiverWater (PlaneGeometry + CanvasTexture)` ➡️ `BABYLON.WaterMaterial` บน Ground Mesh
3. `FireworksManager (BufferGeometry Points)` ➡️ `BABYLON.ParticleSystem`
4. `HTML UI Overlay` ➡️ `BABYLON.GUI.AdvancedDynamicTexture.CreateFullscreenUI()`
